Thông tin Hardening & Bảo mật
  • Non-root Containers:
    Node.js chạy user node (1000), Prometheus user nobody, Grafana user 472, Loki user 10001.
  • Network Isolation:
    Phân chia mạng riêng biệt: frontend-net, backend-net, monitoring-net. MySQL không mở port trực tiếp ra Internet.
  • Database Least Privilege:
    Ứng dụng kết nối bằng user student_user chỉ có quyền SELECT, INSERT, UPDATE, DELETE trên qlsinhvien, không dùng root.
  • Nginx Security Headers & SSL:
    HTTPS SSL/TLS 1.2+1.3, HSTS, X-Content-Type-Options: nosniff, X-Frame-Options: SAMEORIGIN, ẩn server_tokens.
  • Resource Limits & Security Opts:
    Thiết lập giới hạn RAM (mem_limit) và CPU cho từng container, security_opt: no-new-privileges:true.
